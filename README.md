# Ferhat Ullah Khan — Developer Portfolio

A responsive single-page personal portfolio showcasing verified .NET, Azure and full-stack engineering experience.

## View the website

After GitHub Pages is enabled, the site will be available at:

**https://ferhatkhan.github.io/ferhat/**

## Enable GitHub Pages

1. Visit this repository's **Settings** tab.
2. In the left menu, select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the **master** branch and **/(root)** folder, then **Save**.
5. Wait for GitHub Pages to complete its deployment, then open the URL above.

The website is a single `index.html` file with embedded CSS and minimal JavaScript. There are no build dependencies.

## Customize

Edit `index.html` to update the introduction, career experience, skills, or links.

Professional engagement summaries intentionally omit confidential client source code and internal details.
